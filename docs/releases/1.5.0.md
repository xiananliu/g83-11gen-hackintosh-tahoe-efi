Toshiba dynabook G83/HS Hackintosh EFI 1.5.0，本次更新核显驱动和睡眠组件，其他驱动与配置沿用 1.4.9。

## 本次改进

- **修复部分 Tiger Lake 机型内屏启动黑屏**：核显升级为 Dynabook WhateverXe 0.8.5 eDP 修复版，改善驱动接管时内屏无法点亮的问题；原有的 HDMI 4K@60Hz、背光和显示时钟修正保持不变。启动参数新增 `-wex-edp-rate-auto`，1.5.0 的 `config.plist` 已默认加入。详见 [0.8.5 eDP 修复版](https://github.com/xiananliu/wex-modified-edition/releases/tag/0.8.5-edp-fix)。
- **改善睡眠深度与待机表现**：S0ixStandby 更新至 0.5.15，提高进入深度睡眠的成功率，帮助机器达到更低的待机功耗。若更新后遇到睡眠或唤醒异常，可临时加入 `-s0ixnohpetfix` 或 `-s0ixnosold3` 排查。详见 [S0ixStandby v0.5.15](https://github.com/labrouss/S0ixStandby/releases/tag/v0.5.15)。
- **图形组件继续配套 WhateverXe Graphics 0.4.5**：已安装 0.4.5 的用户无需重复安装；仍在 0.4.4 的用户需要先更新。

## 升级步骤

1. 建议更新完整 EFI，并保留自己机器的 `SystemSerialNumber`、`MLB`、`SystemUUID` 和 `ROM`。若只替换 `WhateverXe.kext` 和 `S0ixStandby.kext`，请同步在 `config.plist` 的 `NVRAM → Add → boot-args` 中加入 `-wex-edp-rate-auto`。
2. 已安装 [WhateverXe-Graphics-0.4.5.pkg](https://github.com/b00t0x/WhateverXe-Graphics/releases/tag/v0.4.5) 的用户无需重复安装。
3. 更新并重启后，先保存工作，做一次短时睡眠与电源键唤醒测试；如遇睡眠或唤醒异常，可用上面提到的关闭参数排查。
4. 发布包附带 SHA-256 校验文件，可用于检查下载是否完整。

本次验证信息以上游驱动发布页为准；长时间待机耗电与 Tahoe 表现建议按自己的使用环境复测。

Toshiba dynabook G83/HS Hackintosh EFI 1.4.0。**强烈建议从旧版本升级。**

## 本次更新

- WhateverXe 同步上游 0.8.2 最新代码，并保留 Dynabook 的 HDMI 4K60、内屏时钟和背光修正。启动参数已随 EFI 更新。
- GPU 卡死问题已大幅减轻。在本机实测中，App Store 未再卡死，腾讯会议摄像头正常。浏览器播放某些在线视频仍偶尔会卡死，出现频率比旧版低很多。
- 移除了上一版自行实现的 GPU 修复方案。GPU 卡死涉及底层驱动，本项目后续将通过同步 WhateverXe 上游代码逐步改善稳定性，停止维护独立的 GPU 卡死补丁。

## 升级步骤

1. 更新 EFI，保留自己机器的 `SystemSerialNumber`、`MLB`、`SystemUUID` 和 `ROM`。新装请按 [EFI 使用说明](https://github.com/xiananliu/g83-11gen-hackintosh-tahoe-efi#6-使用说明)生成。
2. 进入 macOS 后，**必须安装配套的 [WhateverXe-Graphics-0.4.4.pkg](https://github.com/b00t0x/WhateverXe-Graphics/releases/download/v0.4.4/WhateverXe-Graphics-0.4.4.pkg)**，安装后重启。已有 0.4.4 可直接使用。

驱动与参数说明见 [Dynabook WhateverXe 0.8.2](https://github.com/xiananliu/wex-modified-edition/releases/tag/0.8.2)。

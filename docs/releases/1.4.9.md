Toshiba dynabook G83/HS Hackintosh EFI 1.4.9，本次更新核显配套和常用组件，沿用 1.4.8 的睡眠与唤醒配置。

## 本次改进

- **核显更新至 Dynabook WhateverXe 0.8.5**：合入上游对部分笔记本启动黑屏、图形加速不可用和显示接管的修复，以及 Safari 硬件视频解码兼容改进；保留 G83 的 HDMI 4K60、背光和显示时钟修正。
- **配套 Graphics 升级至 0.4.5**：改善视频画面的颜色转换与缩放，修复特定转换过程中画面中断的问题。系统内需安装 [WhateverXe-Graphics-0.4.5.pkg](https://github.com/b00t0x/WhateverXe-Graphics/releases/tag/v0.4.5)。
- **采用官方推荐的 AMFIAnchor + Injector**：替换旧 AMFIPass Mod，为核显运行组件提供签名信任支持。
- **更新睡眠组件 S0ixStandby 至 0.5.9**：改进显示固件信息的识别，保留四端口异常唤醒屏蔽和电源键唤醒支持。
- **更新 IntelMausi 至 1.0.8**：合入有线网卡驱动的小问题修复。
- **更新 SimpleHDA 至 1.0.2 正式版**：更新 Tahoe 音频恢复组件，并包含上游新增的 macOS 27 音频兼容处理；整套 EFI 的系统要求仍以 README 为准。
- **更新并启用 RealtekCardReaderFriend 1.0.5**：让“系统信息 → 读卡器”正常识别和显示内置 Realtek 读卡器。

公开包中的机器标识保持空白；升级覆盖前请保留自己的 SystemSerialNumber、MLB、SystemUUID 和 ROM。

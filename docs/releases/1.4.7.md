Toshiba dynabook G83/HS Hackintosh EFI 1.4.7，配置质量修复，包含 1.4.6 的更新。

## 1.4.7 · 配置校验修复

本版不更换任何驱动、不改任何功能开关，目标是让 `config.plist` 通过 OpenCore 1.0.8 官方 `ocvalidate` 校验（此前报 27 项问题，现为 0 项）：

- 将校验器拒绝的 18 条非 ASCII 注释转为 ASCII，原含义保留
- 从 ACPI Add 删除不属于该结构的 `Arch` / `MinKernel` / `MaxKernel` 键
- 为两个 ACPI Patch 补齐缺失的 `Base` / `BaseSkip` / `Mask` 默认值
- 删除 VoodooGPIO / VoodooI2CServices 在 Kernel Add 中多余的 `Path` 键
- 将 VoodooGPIO、VoodooI2CServices 加载顺序调整到 VoodooI2C 之前（依赖先行；此前依赖内核自动兜底解析，功能未受影响，此为规范化修正）

验证：官方 ocvalidate 1.0.8 报 0 项问题；实机（macOS Sequoia 15.8.2）开机、触摸板、Wi-Fi、声卡、睡眠唤醒实测无变化。

## 升级步骤

1. 更新 EFI，保留本机的 `SystemSerialNumber`、`MLB`、`SystemUUID` 和 `ROM`。新装请按 [EFI 使用说明](https://github.com/xiananliu/g83-11gen-hackintosh-tahoe-efi#6-使用说明)生成。
2. 本版无驱动变更，无需重装 WhateverXe-Graphics 或 TGLDmic 组件。
